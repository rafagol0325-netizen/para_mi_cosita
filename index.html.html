Guía para publicar tu web en GitHub Pages

Sigue estos sencillos pasos para tener tu enlace público listo para compartir por WhatsApp:

  1. Guarda este archivo: Guarda este archivo en tu computadora con el nombre exacto de index.html.
  2. Entra a GitHub: Inicia sesión en github.com (o crea una cuenta gratuita si no tienes una).
  3. Crea un nuevo repositorio: Haz clic en el botón verde "New" o en el símbolo "+" arriba a la derecha. Nómbralo por ejemplo aniversario. Asegúrate de marcarlo como Public (Público).
  4. Sube el archivo index.html: En la pantalla que aparece, busca la opción que dice "uploading an existing file". Arrastra tu archivo index.html y presiona el botón verde "Commit changes".
  5. Activa GitHub Pages:
    • Ve a la pestaña Settings (Configuración) de tu repositorio.
    • En el menú lateral izquierdo, haz clic en Pages.
    • En la sección Build and deployment / Branch, selecciona la rama main (o master) y haz clic en Save.
  6. ¡Listo!: Espera unos 1 a 2 minutos, recarga la página y arriba te aparecerá un recuadro verde con tu enlace público (algo como: https://tu-usuario.github.io/aniversario/). ¡Copia ese link y envíaselo!
